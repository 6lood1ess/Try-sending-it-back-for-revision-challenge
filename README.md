# Лабораторная работа: Определение углов треугольника по формулам

## Автор
Захаров Никита (Вариант 6)

## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчета углов треугольника.

## Описание
Программа вычисляет углы треугольника ABC и проверяет величину угла C отдельной формулой.

## Исходные данные
- Сторона a: 3.847 см
- Сторона b: 5.33 см
- Сторона c: 7.167 см

## Ожидаемые результаты
Программа выводит значения углов треугольника в радианах и значение проверочной формулы угла C.
